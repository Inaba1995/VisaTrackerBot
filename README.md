# Italy Visa Tracker Bot

Telegram-бот для отслеживания появления слотов на визу в Италию из России.

Периодически проверяет сайты визовых центров и уведомляет, когда появляются доступные записи.

## Быстрый старт

```bash
pip install -r requirements.txt
```

Создай `.env` из `.env.example` и укажи `BOT_TOKEN`:

```bash
cp .env.example .env
# отредактируй .env — вставь токен бота
```

Запуск:

```bash
python bot.py
```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/check` | Проверить слоты сейчас |
| `/sources` | Список отслеживаемых сайтов |
| `/subscribe` | Подписаться на уведомления |
| `/interval` | Интервал проверки |

## Как это работает

1. Бот проверяет сайты визовых центров (VFS, prenotami и др.)
2. Ищет ключевые слова: "доступно", "available", "slot", "есть"
3. При нахождении — отправляет уведомление всем подписанным пользователям

## Настройка источников

В `config.py` переменная `VISA_SOURCES` — массив словарей с полями:
- `name` — название источника
- `url` — URL для проверки
- `keywords` — список ключевых слов для поиска

Можешь добавлять свои источники (Prenotami, VFS, посольства и т.д.)
